# OpenCode - Lukla Operations Engine 

Repository terstruktur untuk Vibe Coding - conversational Q&A dan exploratory coding di Kiro untuk Lukla Operations Engine.

## Struktur Direktori

### `components/`
Reusable components yang bisa langsung copy-paste atau dimodifikasi:
- React components dengan contoh props
- Backend utilities dan helpers
- Custom hooks dan context providers
- Database helpers dan query builders
- Validation schemas dan middleware

### `snippets/`
Code snippets untuk quick reference saat coding:
- API endpoint patterns
- Common React patterns
- Database query examples
- Error handling patterns
- Testing utilities
- Styling/CSS utilities

### `examples/`
Working examples dan mini-projects:
- Feature implementations
- Full flow examples (API + Frontend + DB)
- Integration examples
- Real-world use cases

### `conventions/`
Style guides dan coding standards:
- Naming conventions
- File structure patterns
- Code style guidelines
- Best practices checklist

## Cara Menggunakan Saat Vibe Coding

### Cari Component/Snippet
Tanya AI: "Ada component untuk X di OpenCode?"
→ AI akan cek folder `components/` atau `snippets/`

### Copy & Modify
Ambil code dari sini, modify sesuai kebutuhan, AI akan help menyesuaikan

### Quick Reference
Tanya: "Bagaimana pattern untuk Y?"
→ AI lihat contoh di `conventions/` atau `examples/`

### Menambah Hasil Coding
Saat sudah implement feature baru:
1. Copy file jadi ke `components/` atau `examples/`
2. Add comments & documentation
3. Update `INVENTORY.md`

## Quick Start

1. **Browsing**: Cek `INVENTORY.md` atau folder mana yang ada
2. **Asking**: Tanya AI tentang component/pattern yang butuh
3. **Using**: Copy-paste, modify, AI bantu kalau perlu
4. **Saving**: Simpan hasil jadi ke OpenCode untuk reuse

Lihat `INVENTORY.md` untuk daftar lengkap semua yang tersedia.
