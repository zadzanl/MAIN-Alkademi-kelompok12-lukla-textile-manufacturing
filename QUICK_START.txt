🆘 TROUBLESHOOTING

Port Already in Use?
  Backend:  Change port in command: --port 8008
  Frontend: Edit vite.config.ts, change port: 3008

Backend not found?
  - Check: http://127.0.0.1:8007/api/sampling-spec-rnd/health
  - Restart backend
  - Check virtual environment is activated

npm install stuck?
  Try: npm install --legacy-peer-deps
